# 🛠️ Class Constructor for Akequ.Base.PlayerClass

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Type](https://img.shields.io/badge/Platform-Web_Static-orange.svg)

**Class Constructor** — это интерактивный визуальный инструмент (генератор кода), разработанный для упрощения создания новых игровых классов на базе фреймворка **Akequ.Base.PlayerClass**. Настраивайте параметры персонажа визуально и получайте готовый C# код мгновенно.

---

## 🚀 Возможности

*   **Live Preview:** Код обновляется в реальном времени при изменении любого поля.
*   **Гибкая настройка:**
    *   Управление HP через конфиг и значения по умолчанию.
    *   Визуальный выбор цвета (Hex/ColorPicker) для UI.
    *   Автоматическая привязка Ragdoll к выбранной модели.
*   **Динамические списки:**
    *   **Инвентарь:** Добавление неограниченного количества предметов при спавне.
    *   **Голосовые каналы:** Настройка доступных каналов связи (3D, Intercom, SCP).
*   **Методы Overrides:** Включение/выключение стандартных функций (CanMove, OnOpenInventory, Resistance) через переключатели.
*   **Оптимизация:** Чистый C# код на выходе, готовый к вставке в проект.

## 📖 Инструкция по использованию

1.  **Настройка базы:** Введите `Namespace` и `ClassName`. Это определит название вашего `.cs` файла.
2.  **Визуализация:** Выберите `DisplayName` (поддерживает HTML-теги для RichText) и цвет класса.
3.  **Логика спавна:** Укажите точку появления (`Spawn Point`) и ID команды (`Team ID`).
4.  **Инвентарь:** Нажмите "Добавить предмет", чтобы расширить стартовый набор игрока.
5.  **Дополнительно:** Раскройте секцию "Overrides", чтобы настроить специфическое поведение (например, разрешить проход через чекпоинты без карт).
6.  **Результат:** Нажмите кнопку **"Копировать"** в правой панели и вставьте код в свой проект в IDE.
